# Job Agent Dashboard

Public, sanitized presentation layer for the private Job Search Agent.

## Setup
1. Create a public GitHub repository named `job-agent-dashboard`.
2. Copy these files into it and push to `main`.
3. In Settings -> Pages, choose **GitHub Actions** as the source.
4. The Pages workflow deploys `index.html` and the `data/jobs.json` file published by the private agent.

Do not put resumes, API keys, profiles, search configuration, or private data in this repository.
